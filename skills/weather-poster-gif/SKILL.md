# 天气海报轮播

用于把一张固定设计稿批量改成多城市天气轮播：擦除原有变量文字，严格保留用户给出的城市和温度写法，生成可配置速度的透明静态帧和透明 GIF。

## 适用条件

- 原图有固定的商品、背景或标题，只有城市名和温度等少数槽位需要替换。
- 待擦除文字明显亮于周围底图。
- 海报外侧使用黑底，适合通过边缘连通区域提取透明背景。
- 如果原图不是黑色外底，或待擦除文字与背景亮度接近，先调整配置并小样试跑，不要直接批量生成。

## 工作流

1. 检查原图，区分固定内容与变量内容。用户没有明确要求删除固定标题时，擦除区域不要覆盖标题。
2. 用像素坐标确定 `erase_regions`、各文字槽位的中心点和最大宽度。配置字段见 [references/config.md](references/config.md)。
3. 将用户原文放入条目 JSON。城市、温度、分隔符和单位必须保持用户给出的写法，不擅自把“10-1°C”改成“10～-1°C”。
4. 运行脚本：

```bash
python3 scripts/weather_poster_gif.py \
  --source /path/to/poster.png \
  --items /path/to/items.json \
  --config /path/to/config.json \
  --output-dir /path/to/output
```

5. 优先检查透明棋盘预览和全帧预览。出现位置偏差、长文字越界或旧文字残影时，只调整配置坐标与字号范围，再重新运行。
6. 交付透明 GIF、透明 PNG 压缩包和棋盘格预览，并报告帧数、每帧时长和总时长。

## 关键约束

- 透明 GIF 使用二值透明通道。GIF 不支持半透明边缘，因此必须从画布边缘提取连通的黑色背景，不能把所有黑色像素都设为透明，否则黑色商品也会被误删。
- 透明 GIF 的调色图必须保留原彩色调色板，并单独把索引 `255` 保留给透明像素。不要通过重建 P 模式图像来设置透明色。
- 应用或聊天窗口使用深色背景时，透明区域会看起来是黑色。必须提供棋盘格预览来验证真实透明通道。
- 文字按可见像素边界居中，并按 `max_width` 自动缩小字号。较长的城市名不能被裁切。
- 每帧时长保持完全一致；常用值为 `500ms`、`650ms` 或 `800ms`。用户只要求“慢一点”时，保留原版本并新增版本化文件。
- 默认写入新目录。目标目录非空时必须取得用户明确覆盖意图，再使用 `--overwrite`。
- 脚本依赖 `Pillow`、`numpy` 和 `scipy`。

## 输出

脚本会生成：

- 清空文字底图。
- 普通静态帧和透明 PNG 静态帧。
- 不透明 GIF 和透明 GIF。
- 透明棋盘格预览与全部帧缩略拼图。
- 透明静态帧 ZIP。
- `生成摘要.json`，记录成品路径、透明校验和 GIF 帧数、时长、循环信息。
