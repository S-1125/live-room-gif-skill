# 跑马灯

稳定脚本：`scripts/marquee_gif.py`。优先使用该脚本，不要在同类需求中重复编写临时排版代码。

## 硬性规则

- 跑马灯必须保持横向一行，禁止把文案拆成多行。
- 运动方向默认从左到右。
- 使用无缝循环：条带首尾周期一致，循环回到首帧时不能跳变。
- 同一跑马灯内默认匀速，不随意加入停顿。
- 避免文字或图片在边框外被生硬截断；需要时在横幅左右边缘做短距离渐隐。
- 用户原文逐字保留，包括分隔符、单位、数字和空格。

## 纯文本跑马灯

- 默认只有文本，不额外堆叠商品卡或装饰图层。
- 用户给出直播间风格图时，只提取配色、圆角、描边、阴影、材质和氛围，不照搬截图中的无关内容。
- 用户没有设计稿时，根据直播间的品牌色和品类气质生成横幅底图。
- 用户明确要求无底座时，删除胶囊或矩形底板，只保留文字、描边和必要阴影。
- 文案宽度超过可视区域时，重复拼接并留出固定循环间隔。
- 文案较短但用户明确要求跑马灯时，仍应形成可感知的连续运动，而不是单帧静止。

## 图片跑马灯

- 必须把商品或素材拆成独立卡片，再排成唯一一行；禁止把原始拼图整张滚动。
- 图片由用户提供时，优先使用原素材，不生成近似商品替代。
- 图片未提供时，先确认商品、数量、风格和尺寸；再生成透明或纯色背景素材，最后制作跑马灯。
- 卡片尺寸、圆角、边框、间距和阴影保持一致。
- 商品图片可以拥有各自的设计边框，但除非用户明确要求，不得额外添加包住整排商品的大底板。
- 截图拼图中的白边、编号或其他无关元素应在裁切时去除。

## 稳定命令

纯文本、无底座：

```bash
python3 scripts/marquee_gif.py text \
  --output-dir outputs/text-marquee \
  --text "幸棉保暖家居｜双面绒三件套｜..." \
  --width 1080 \
  --height 100 \
  --font-size 46 \
  --duration-ms 80 \
  --step-px 10 \
  --edge-fade-px 28
```

商品图片、单图边框、无整排底板：

```bash
python3 scripts/marquee_gif.py images \
  --output-dir outputs/image-marquee \
  --collage products.png \
  --crop-box 5,8,194,232 \
  --crop-box 201,7,390,234 \
  --width 1080 \
  --height 276 \
  --item-width 190 \
  --item-height 240 \
  --duration-ms 80 \
  --step-px 10
```

如明确不需要单图边框，增加 `--no-border`。

## 审核参数

交付时明确：

- 画布尺寸。
- 单行内容周期宽度。
- 帧数、单帧时长、总时长。
- 每帧位移和移动速度。
- 循环方式与透明方式。
- 图片总数及排列顺序。

已审核案例见 [case-registry.md](case-registry.md) 的 `002` 和 `003`。
