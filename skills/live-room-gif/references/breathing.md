# 缩放呼吸循环

稳定脚本：`scripts/breathing_gif.py`。

## 已审核参数

- 默认缩放范围：`90% → 100% → 90%`。
- 默认 120 帧，`30ms/帧`，总时长 `3.6 秒`。
- 使用余弦曲线，首尾最小、中点最大。
- 围绕画布中心等比缩放，不添加上下位移。
- 透明背景和原图 alpha 保持不变。

## 关键实现

- 慢速缩放必须使用浮点仿射缩放，不能先取整尺寸再缩放；整数尺寸会在最高点和最低点附近产生重复帧，被 GIF 编码器合并后造成不均匀停顿。
- 最大缩放默认不超过原画布比例，避免内容边缘被裁掉。
- 用户要求更强或更弱的呼吸感时，只调整 `--min-scale`；最大缩放保持 `1.0`，除非输入素材本身留有额外安全画布。
- 用户要求更快或更慢时，优先调整帧数或单帧时长，保持一轮的完整余弦曲线。

## 命令

```bash
python3 scripts/breathing_gif.py \
  --image input.png \
  --output-dir outputs/breathing \
  --name 商品呼吸 \
  --min-scale 0.90 \
  --max-scale 1.00 \
  --frames 120 \
  --duration-ms 30
```

## 审核

- 最大和最小尺寸是否均完整显示。
- 中心位置是否保持稳定。
- 峰值是否位于一轮动画中点。
- 首尾是否会跳变。
- GIF 是否仍保留完整 120 帧和统一 30ms。
