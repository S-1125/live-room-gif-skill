# 扫光动画

稳定脚本：`scripts/sweep_gif.py`。同类需求优先复用该脚本。

## 已审核参数

- 默认方向：`top-left-to-bottom-right`，即光带从左上向右下推进。
- 其他可用方向：`bottom-left-to-top-right`。
- 默认 48 帧，`80ms/帧`，总时长 `3.84 秒`。
- 核心最高不透明度：`98%`。
- 宽光宽度系数：`0.22`；核心宽度系数：`0.105`。
- 透明区域保留 alpha，不填充黑底或白底。
- 内容周围透明空白可自动裁切，默认保留 `28px` 安全边距。

## 核心画法

- 扫光由宽柔光和宽核心两部分组成，不能只做一条窄高光。
- 宽光与核心同时叠加时，必须限制总峰值，避免整张图被洗成纯白。
- 高亮颜色优先使用白色或与参考图一致的明亮色，但核心必须明显亮于原图。
- 高光只作用于原图 alpha 内容，透明背景不能被照亮。
- 边缘需要可感知的柔和过渡，但不能把整个画面都纳入高亮范围。

## 方向

- `top-left-to-bottom-right`：适合竖版海报、商品图、从上往下阅读的视觉。
- `bottom-left-to-top-right`：适合部分横向标识，但必须检查是否与内容走向冲突。
- 用户指出方向不舒服时，只翻转方向斜率，不要同时改动亮度、宽度和节奏。

## 命令

```bash
python3 scripts/sweep_gif.py \
  --image input.png \
  --output-dir outputs/sweep \
  --name 商品扫光 \
  --color "#D6F8FF" \
  --direction top-left-to-bottom-right \
  --frames 48 \
  --duration-ms 80 \
  --opacity 0.98
```

需要保留原始大画布时增加 `--preserve-canvas`。需要调整带宽时优先小范围修改 `--band-width` 和 `--core-width`，不要同时盲目提高 `--opacity`。

## 审核

至少检查：

- 扫光总宽度是否接近参考图，而不是只看核心。
- 核心是否足够亮但不把文字或商品洗白。
- 倾斜方向是否与内容走向冲突。
- 48 帧是否全部保留，是否存在局部停顿。
- 透明四角是否正确，边缘是否残留底色。
